# Vestiaire

La tenue du jour, choisie selon la météo de chez vous.

- Géolocalisation du navigateur (ou recherche de ville)
- Météo [Open-Meteo](https://open-meteo.com), sans clé d'API
- Tenue selon le ressenti, la pluie, le vent, l'UV et l'écart de température dans la journée
- Trois styles : Ville, Décontracté, Habillé — aujourd'hui ou demain

Un seul fichier `index.html`, servi par GitHub Pages.
